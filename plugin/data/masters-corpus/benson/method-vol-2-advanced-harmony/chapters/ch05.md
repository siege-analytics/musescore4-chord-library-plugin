## Pedal point definition

> Pedal point, also known as pedal tone or pedal note, is a sustained note while other notes
>   are moving. Usually, we use this concept to create a sequence of chords using the same
>   bass note.
>
>   However, we can use a pedal point to create sequences of chords that have the same note
>   on the top. We call this an "inverted pedal". In addition to using this concept on the lower
>   and higher notes, we can still use it for notes between the bass and the upper notes.
>
>   This concept has been used since the early baroque era, and works to create tension in the
>   harmony, breaking the monotony of common chords. On the guitar, we often use bass
>   pedal points using open strings. We can apply it using the D, A or E strings. However, we
>   can use what we call drop "D" tunning, which is tunning the E string into "D".

**Significance (p. 169).** Defines pedal point, inverted pedal, and inner pedal in one passage, and names the specific open strings used for guitar bass pedal points, including Drop D tuning.
