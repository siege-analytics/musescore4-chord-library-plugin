# Chapter 3 — Pentatonic Scale

_Distillation; backed by `chapters/ch03.md`._

Chapter 3 teaches the pentatonic scale, a five-note framework with major and minor forms that are relative to each other (C6 and Am7 share the same notes), and introduces the core rule that these must be visualized separately to navigate the guitar's five-zone fretboard system. The characteristic pedagogical move is the 5-zone system using guide chords as navigational aids rather than harmonic rules, exploiting the two-notes-per-string structure that allows vertical playing. Key load-bearing terminology includes the relative major/minor pentatonic relationship, the 5-zone system with zone-skipping to preserve hand synchronization, and the zone-connection picking problem that requires careful attention to 1st or 6th string changes. The chapter establishes essential technical rules: skip zones to maintain hand connection, use the non-standard 4-1-4-1 finger alternation for zone transitions, and preserve melodic patterns by keeping note order fixed while varying rhythm alone. Practical guidance emphasizes selective study of preferred patterns and simple pentatonic patterns paired with rhythmic cells rather than exhaustive mastery of all possibilities.
