# Chapter 10 — Creating Fingerstyle Jazz Guitar Solos, Part 6: Harmonizing with tenths

_Distillation; backed by `chapters/ch10.md`._

This chapter teaches how to use tenths and sixths as accompaniment intervals in fingerstyle jazz, extending the harmonization principles introduced earlier for thirds. The core technique is walking tenths -- using a note a tenth below the melody to create harmony while accompanying another musician -- which follows the same major/minor adjustment rules as thirds. The chapter emphasizes building automaticity through systematic practice: students cycle through tenths in all keys (proceeding sharp, then flat) using consistent fingering patterns, treating this drill as an ongoing project like scale work. Sixths are introduced as functionally equivalent to thirds and tenths, operating under the same harmonic logic where a sixth below the melody note produces a chord tone whose relationship depends on the melody note's role in the chord (root, third, fifth, or seventh). The key load-bearing concepts are the interval-to-chord-tone mapping (how each scale interval relates to underlying harmony) and the decision-point rule (when a scale-derived sixth creates an extension or clash, the player can accept or adjust the note for clarity). Sixths are presented as multipurpose, serving both as melodic shadows and bass notes.
