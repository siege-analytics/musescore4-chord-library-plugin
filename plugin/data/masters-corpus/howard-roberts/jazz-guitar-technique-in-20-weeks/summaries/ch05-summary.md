# Chapter 5 — LINE SHAPING

_Distillation; backed by `chapters/ch05.md`._

Chapter 5 outlines the structural framework and pedagogical strategy of a 20-week guitar method program designed to reach ♪ = 126 through daily 50-minute practice sessions, six days per week. The program divides into three phases: **duple time** (weeks 1–6, using eighth notes and subdivisions), **triple time** (weeks 8–13, using triplet feels), and **tempo solidification and legato techniques** (weeks 15–17). Key teaching moves include transposing chord progressions to stimulate fresh fingering approaches and introducing **legato techniques** — hammer-ons, pull-offs, and glissandi — which accelerate speed by allowing multiple notes per picking stroke. The appendix supplies reference line models (numbered 1-A, 1-B, etc.) that correspond to each project lesson, grounding the program's abstract structure in actual musical content. Central to the method is the principle that speed is always subordinate to precision and accuracy, and that tempo becomes a permanent motor reflex rather than a conscious effort.
