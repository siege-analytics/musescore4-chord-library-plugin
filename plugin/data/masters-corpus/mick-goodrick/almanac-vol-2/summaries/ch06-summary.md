# Chapter 6 — MORE ABOUT 4THS

_Distillation; backed by `chapters/ch06.md`._

This chapter presents two core elements: a taxonomy of five M-Lode applications (melodies, arpeggios, counterpoint, 3-part chords, and 4-part chords) defining how any material in the system can be deployed, and a specific technique rule for arpeggio alternation — ascend on one chord, descend on the next. Together these establish both the foundational methods for working with harmonic content and an operational principle for arpeggiated performance. The five-application taxonomy is load-bearing because it provides the structural framework for organizing all subsequent material, while the alternation rule operationalizes that framework.
