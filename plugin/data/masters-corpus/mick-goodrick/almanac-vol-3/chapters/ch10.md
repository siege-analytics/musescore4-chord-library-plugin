## Intervallic vs. functional voice-leading

> Intervallic Voice-Leading
> 7 → 2nd
> 5 → 2nd
> 3 → 2nd
> 1 → c.t.
> B → D → D → F → F → A → A → C
> G → A → B → C → D → E → F → G etc.
> C → C → E → E → G → G → B → B
> E → F → G → A → B → C → D → E
>
> Functional Voice-Leading
> 1
> 7
> 3
> 5
> Ascends
> 2 different voicing alternate (drop 3; drop 2 & 4)
> 2 voices are the cycle
> M.S.R.P.

**Significance (p. 32).** This illustrates the book's core analytical framework distinguishing intervallic motion (how far each voice moves) from functional role (which chord tone carries which voice), with the M.S.R.P. as the memorizable sequence.
